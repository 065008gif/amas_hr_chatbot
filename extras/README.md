# extras/: useful files that git normally ignores

The working folders `.cache/` and `data/runtime*/` are ignored by git. They hold caches, build staging, logs and local databases. The useful, secret-free files among them were copied here on 29 September 2026 so the work can be reproduced on another PC. Nothing here holds a key, a token or real personal data (everything shows fictional demo data), and the secret scan covers this folder like the rest of the repository.

The **raw evaluation runs are not here because they are already tracked**: `tests/results/*_runs.jsonl` (final runs) and `*_runs_v1.jsonl` (first runs), with the scored `.json`/`.md` files and `RESULTS.md`.

## What is in this folder

| Folder | Contents | Where it came from |
|---|---|---|
| `screenshots/phase6/` | 17 screenshots of the first portal design (Phase 6, D-038): sign-in, home, chat, citations, tickets, library, viewer, insights, about, phone views | `.cache/screens/*.png` |
| `screenshots/redesign_before/`, `redesign_after/` | The 12 before and 12 after screenshots of the colour redesign (D-042), desktop 1440×900 and phone 390×844, plus the extra "after" pages (sign-in, empty chat, about, viewer) | `.cache/screens/before/`, `after/` |
| `screenshots/montages/` | Side-by-side phone and desktop montages used to review the redesign | `.cache/screens/*montage*.png`, `after-*.png` |
| `screenshots/scripts/` | The headless-Chrome scripts that took every screenshot (`shots*.mjs`; `live_report.mjs` for the report's live-site shots; `arch.html` + `arch.mjs` for the architecture diagram), with their `package.json` and `package-lock.json` (puppeteer-core) | `.cache/screens/` |
| `screenshots/fixtures/` | The four real `/api/chat` responses (answer with a conflict, answer, POSH escalation, not found) that `shots3.mjs` replays, so the before/after chat screenshots show the same conversation | the session scratchpad |
| `eval/eval_quant.{json,txt}` | Retrieval evaluation of the fp32 against the int8-quantized reranker, behind the decision to ship the quantized model (D-040) | `.cache/` |
| `report/Nia_HR_Helpdesk_Report.pdf` | A PDF rendering of the final report (LibreOffice), for reading without Word | `.cache/report_render/` |

**Using the screenshot scripts:** `cd extras/screenshots/scripts && npm ci`. The scripts were written for this Linux PC: they expect Chrome at `/usr/bin/google-chrome`, save into `/home/ashok/hrbot/...` and use the demo portal at `http://localhost:5173` (or the live site for `live_report.mjs`). Change `executablePath`, `OUT` and `BASE` at the top of each script for another machine. `shots3.mjs` reads its fixtures from `../fixtures` (or from the folder named in the `FX` environment variable).

## Every git-ignored item in the project, and what was done with it

| Ignored path | What it is | Decision |
|---|---|---|
| `.env` | The real API keys | **Never copied.** Recreate it from `.env.example` (RUN_LOCALLY.md step 4). |
| `.cache/screens/` (images, scripts) | Screenshots and capture scripts | Copied (above). |
| `.cache/screens/chrome-profile/`, `.cache/screens/chrome-live/` | Headless Chrome profiles | Not copied: a browser profile can hold cookies and site data. |
| `.cache/screens/node_modules/` | puppeteer-core install | Not copied: reinstall with `npm ci` from the copied lockfile. |
| `.cache/eval_quant.*` | Reranker quantization evaluation | Copied (above). |
| `.cache/report_render/*.pdf` | PDF rendering of the report | Copied (above). The page images there are review scratch and not copied. |
| `.cache/fastembed/`, `.cache/huggingface/` | Model download caches | Not needed: the models used at run time are committed in `backend/models/`, and ingestion now uses them too (D-055). |
| `.cache/reranker-fp32.onnx`, `.cache/reranker-quantized.onnx` | Reranker model files (91 MB and 23 MB) | Not copied: the quantized one is committed in `backend/models/`; the fp32 one is only needed to repeat `eval_quant` and can be downloaded again. |
| `.cache/space-stage/`, `space-upload/`, `space-venv/`, `vercel-bundle/`, `uv-*`, `venv-fresh/`, `clone-test/`, `fe-fresh/` | Staging folders and test environments from deployment and reproducibility checks | Not needed (rebuilt by the commands in RUN_LOCALLY.md). |
| `.cache/docxgen/`, `.cache/lo-profile/` | docx library install and LibreOffice profile used to build and render the report | Not needed (`report/package.json` now pins the library). |
| `.cache/*.log`, `.cache/preview/`, `.cache/report_*` text files | Logs and scratch files | Not needed. |
| `data/runtime/`, `data/runtime-dev/`, `data/runtime/eval/` | Local SQLite databases (tickets, answer cache, anonymised logs) from development and evaluation runs | Not copied: they are regenerated by running the app or the evaluations, and they hold only demo tickets and anonymised logs. |
| `frontend/node_modules/`, `report/node_modules/`, `frontend/dist/` | Installed packages and the frontend build | Not needed: `npm ci` and `npm run build`. |
| `**/__pycache__/` | Python bytecode | Not needed. |
